## 2. الرحلات العامة (قبل الدخول)

### 2.1 تسجيل مؤسسة/معلم (`/register-school`)
- يعمل وينشئ tenant حقيقياً (R2-5)، وزمنه على Supabase تقريباً 17 ثانية بعد تحسين القالب.
- شاشة النجاح تعرض الاسم والـ slug والبريد ورابط `/login?tenant=slug`. **جيد.**
- **فجوة:** لا توجد قائمة "خطوات البدء" بعد أول دخول (أنشئ مقرراً، أضف طلاباً، فعّل الخدمات). المدير يصل إلى لوحة مؤشراتها صفر. (P3)
- قيمة نوع المؤسسة تظهر بالإنجليزي داخل الواجهة العربية: "معلم مستقل (Individual Teacher)" (`register-school/page.tsx:189`, `create-tenant-modal.tsx:34`). (P3)

### 2.2 تسجيل الطالب ذاتياً (`/register`، REG-1)
- 6 خطوات مع شريط تقدم، تحقق سعودي (الهوية والجوال)، ويختار حتى 5 مؤسسات. التصميم جيد.
- **J-01 (P0):** `login/page.tsx:199-210`: الحقل `label="البريد الإلكتروني"` و`type="email"` و`required`. الخادم يقبل الجوال (REG-1)، لكن تحقق المتصفح يمنع الإرسال. **العلاج:** حقل "البريد أو رقم الجوال" بـ `type="text"` و`inputMode` مناسب.
- **J-02 (P0):** شاشة النجاح (`features/registration/request-card.tsx`) تعرض رمز المرجع فقط. لا يوجد:
  - رمز الأكاديمية أو رابط دخول لكل مؤسسة اختارها الطالب.
  - صفحة "تابع حالة طلبي" (الـ API `GET /public/registration/status` موجود بدون واجهة، وREG-1 يذكر ذلك).
  - أي إشعار للطالب عند القبول (لا SMS ولا واتساب).
- مراجعة الطلب: `/teacher/registrations` للأدوار التي عندها `students.create` على مستوى tenant. لم يُتحقق منها في المتصفح (REG-1).

### 2.3 الدخول (`/login`)
- تبويبان: كلمة مرور / كود دخول (بطاقة). رمز الأكاديمية يُحفظ على الجهاز ويُطوى بعد معرفته. **جيد.**
- طالب يتبع أكثر من مؤسسة يحتاج يعرف slug كل واحدة؛ لا يوجد اختيار مؤسسة بعد الدخول (P7/ADR-003 ما زال TODO).
