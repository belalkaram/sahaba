## 1. Executive Summary

Phase R6 completes the entire assessment and examination loop across the LMS platform:
1. **Exam Lifecycle Engine (R6-1):** States `draft` → `published` → `closed` → `archived`. Auto-publishing removed on exam creation. Strict pre-publishing invariants enforced: an exam cannot be published without at least 1 question and total points > 0. Master §34 attempt state progression strictly enforced.
2. **Server-Authoritative Timing & Anti-Cheat (R6-2):** `expires_at = min(started_at + duration, closes_at)`. Server-authoritative timer synchronization via `GET /attempts/{id}`. Late answer submissions after expiration are rejected with HTTP 422 `ATTEMPT_EXPIRED` and trigger automatic attempt submission. Concurrent and duplicate submits are idempotent using row-level locking.
3. **Questions API & Course Question Bank (R6-3):** Support for 5 core question types: `multiple_choice`, `multiple_select`, `true_false`, `short_answer` (case-insensitive normalized auto-grading with multiple acceptable answer variations), and `essay` (manual teacher evaluation). Reordering API (`POST /exams/{id}/questions/reorder`). Dedicated Question Bank API (`question_banks` & `bank_questions`) with 1-click batch import into exams. Answers are strictly concealed from students; only staff with `with_answers=1` can inspect answer keys.
4. **Assignment Submissions with Files (R6-4):** Multipart file upload and private storage (`tenant_private`). Enforced due dates, configurable late submission policy (`allow_late`, `late_penalty_percent`), and resubmission permissions. Secure authenticated file download endpoint (`GET /assignments/{id}/submissions/{subId}/file`).
5. **Staff Builders & Grading Desk (R6-5):**
   - `/teacher/courses/[id]/exams/[examId]/builder`: Rich Exam Builder with live question type editors, points, question bank batch import modal, student preview mode, and publishing checklist.
   - `/teacher/grading`: Staff Grading Inbox across teacher's courses, filtering pending assignments and essay exam attempts, individual grading drawers with rubric/feedback, and bulk publish button. Resolves `T-UX-05` (removed `count: 0` placeholder on teacher dashboard).
6. **Student Assessment Console (R6-6):**
   - `/student/assessments`: Unified assessment hub with filters (`open`, `upcoming`, `submitted`, `graded`) and countdowns.
   - `/student/courses/[id]/exams/[examId]/take`: Distraction-free exam runner with synchronized server timer, immediate answer autosaving, network loss detection & retry banner, question palette navigator, and confirmation dialog.
   - `/student/courses/[id]/exams/[examId]/results`: Detailed result review screen adhering to `show_results` policy (`after_publish`, `after_submit`, `never`).
   - `/student/courses/[id]/assignments/[assignmentId]`: Assignment submission workspace with file dropzone, deadline countdowns, and real-time grading feedback.
