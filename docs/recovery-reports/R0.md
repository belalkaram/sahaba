## 4. Behavior Verified

1. **R0-1 Platform Routes Protection:**
   - *Before:* Any unauthenticated client calling `GET /api/v1/tenants` or `POST /api/v1/tenants` received tenant records or provisioned tenants.
   - *After:* Returns 401 Unauthorized unless a valid `PLATFORM_ADMIN_TOKEN` bearer token is supplied.
   - *Proving Test:* `SecurityContainmentR0Test::test_platform_list_tenants_returns_401_without_token`, `SecurityContainmentR0Test::test_platform_routes_return_401_when_env_token_is_empty`.

2. **R0-2 Question `correct_answer` Redaction:**
   - *Before:* `GET /api/v1/courses/{id}/exams` returned full question models including `correct_answer` string directly to enrolled students.
   - *After:* Model hides `correct_answer` by default; controller loads question count only for student role, leaving no leak vector.
   - *Proving Test:* `SecurityContainmentR0Test::test_student_exam_list_does_not_expose_correct_answer`.

3. **R0-3 Payment Request IDOR:**
   - *Before:* Any authenticated student could query any student's payment record at `GET /api/v1/payment-requests/{id}`.
   - *After:* Returns 403 Forbidden unless the authenticated user is the student owner or holds `payments.view` / review permissions.
   - *Proving Test:* `SecurityContainmentR0Test::test_student_cannot_view_another_students_payment_request`, `test_student_can_view_own_payment_request`.

4. **R0-4 Audit Logs Access:**
   - *Before:* Audit logs route allowed any tenant token holder to read logs.
   - *After:* Route explicitly guarded by `tenant.can:audit.view` returning 403 to students and unauthorized staff.
   - *Proving Test:* `SecurityContainmentR0Test::test_student_cannot_view_audit_logs`, `test_staff_with_audit_view_permission_can_view_audit_logs`.

5. **R0-5 One-Time Support Code Flow:**
   - *Before:* Support access generated a long-lived bearer token appended to URL query parameter `?support_token=...`.
   - *After:* Support access issues a 60-second single-use exchange code. Frontend exchanges it server-side via `POST /api/v1/auth/support/exchange` which burns the code immediately upon issuance of the session token.
   - *Proving Test:* `SecurityContainmentR0Test::test_support_exchange_code_can_only_be_redeemed_once`, `test_expired_support_exchange_code_returns_401`.

6. **R0-6 Device Unbind Instead of Random Fingerprints:**
   - *Before:* Device replacement generated client-side pseudo-random strings via `Math.random()`, desynchronizing student devices.
   - *After:* Teacher credential UI unbinds existing device with audit trail. Next valid login binds the student's physical device organically.
   - *Proving Test:* `CredentialLifecycleService::unbindDevice()` & `CredentialController::replaceDevice()`.

7. **R0-7 Honest Health Reporting:**
   - *Before:* Platform dashboard caught fetch errors and rendered `'HEALTHY'` and `'OK'` mocks.
   - *After:* True API state is rendered; connectivity failures display real status without fallbacks.

8. **R0-8 CI Audits Enforcement:**
   - *Before:* `.github/workflows/ci.yml` had `|| true` on security audit steps.
   - *After:* `|| true` removed; `composer audit` and `npm audit` both pass cleanly.

9. **R0-9 Secret Hygiene:**
   - *Before:* Potential risk of leaked API credentials in web bundles or repo.
   - *After:* Verified no `GOOGLE_CLIENT_SECRET` in frontend src or web env files; `.gitignore` verified for tenant sqlite databases.
