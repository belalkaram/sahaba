## 4. Behavior Verified

1. **Mandatory Parent Link on Creation:**
   - Submitting `POST /api/v1/students` without `parent_id` or `parent_name`+`parent_phone` is rejected with HTTP 422 (`VALIDATION_FAILED`).
   - Verified by `ParentLinkRequiredTest::test_creating_student_without_parent_is_rejected_with_422`.
2. **Sibling Linking:**
   - Creating a second student with the same parent phone number links both students to the same parent profile.
   - Verified by `ParentLinkRequiredTest::test_creating_second_student_with_same_parent_phone_links_siblings`.
3. **CSV Import Protection:**
   - CSV row missing parent info is rejected and marked as failed.
   - Verified by `ParentLinkRequiredTest::test_csv_import_row_without_parent_is_marked_failed` and `StudentImportTest`.
4. **Child Link/Unlink (F-10):**
   - Parents can be linked to extra children via `POST /parents/{id}/children` and unlinked via `DELETE /parents/{id}/children/{studentId}`.
   - Verified by `ParentLinkRequiredTest::test_link_and_unlink_child_endpoints_manage_relationships`.
5. **Notification Event Routing (OD-33 Table):**
   - `attendance_absent`: notifies both student and parent.
   - `attendance_late`: notifies both student and parent.
   - `homework_missing`: notifies both student and parent.
   - `grade_published`: notifies both student and parent.
   - `session_reminder`: notifies student only.
   - `weekly_report`: notifies parent only.
   - Verified by `NotificationRoutingTest` (7 tests PASS).
6. **WhatsApp Channel Adapter:**
   - Uses Meta WhatsApp Business Cloud API adapter with fake HTTP tests.
   - Validates Bearer token header, phone sanitization, template names, and language `ar`.
   - Persists records to `whatsapp_message_logs`.
   - Resilient error handling without throwing uncaught exceptions.
   - Graceful fallback to `LogMessagingChannel` when credentials are not configured.
   - Respects parent opt-out: no messages queued when `whatsapp_opt_in === false`.
   - Strict tenant database isolation prevents cross-tenant message leaks.
   - Verified by `WhatsAppChannelTest` (7 tests PASS).
