## 4. Behavior verified

- **OD-23 (Tenant Types):** Individual teachers are provisioned with 4 restricted roles (`owner`, `assistant`, `student`, `parent`) and owner staff type `teacher`. Organizations have all 8 roles and owner staff type `admin`.
- **OD-24 (Simplified Teacher UI):** Navigation bar excludes `admin-roles` and renames branches to "أماكن التدريس والقاعات" for individual teachers.
- **OD-31 (Service Bundling):** Selecting `online` enables online modules and disables offline modules in `tenant_features`. Selecting `offline` does the inverse.
- **F-6 (Super Admin Module Management):** Super admins can inspect and toggle modules and upgrade individual teachers to organizations via `TenantModulesModal`.
- **Teacher Conversion:** Converting `individual_teacher` to `organization` via `POST /tenants/{id}/convert-to-organization` expands roles without data loss and logs audit event `tenant.converted_to_organization`.
