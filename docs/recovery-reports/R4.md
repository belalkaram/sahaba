## 1. Executive Summary

Phase R4 implements the complete core learning loop of the LMS:
1. Hierarchical content structure: Courses → Modules → Lessons → Materials.
2. Server-side authoritative playback tracking, progress aggregation, and anti-abuse detection.
3. Teacher Course Builder workspace for modules, lessons, and materials management.
4. Distraction-free Student Course Player with playback heartbeats, resume position, materials download, and dynamic anti-piracy watermarking.
5. Removal of the simulated fake AI Tutor (`setTimeout` canned responses) in favor of real, verified learning progress and course catalog navigation.

All implementations strictly adhere to `AGENTS.md`: no mock fallbacks, client is not the security boundary, and all access decisions are enforced by `ContentAccessPolicy` on both streaming embeds and material downloads.

## 2. Implemented Architecture & Database Schema

### 2.1 Migrations & Models

1. **`2026_10_31_000004_create_course_modules_and_content_tables.php`:**
   - `course_modules`: `id` (UUID), `course_id`, `title`, `description`, `sort_order`, `status` (`draft`, `published`).

   - `lesson_materials`: `id` (UUID), `lesson_id`, `title`, `kind` (`file`, `link`), `storage_path`, `url`, `mime`, `size`, `sort_order`.
   - Automated backfill: created a default module ("المحتوى الرئيسي") for any existing courses and assigned legacy lessons.

2. **`2026_10_31_000005_create_video_events_and_progress_tables.php`:**
   - `video_events`: `id` (UUID), `student_id`, `lesson_id`, `media_id`, `type` (`start`, `heartbeat`, `seek`, `pause`, `end`), `position_seconds`, `client_ts`.
   - `lesson_progress`: `student_id`, `lesson_id`, `percent` (0-100), `last_position_seconds`, `completed_at`, `watch_seconds`, `rewatch_count`, with `unique(['student_id', 'lesson_id'])`.
   - `abuse_signals`: `student_id`, `lesson_id`, `signal_type` (`speed_anomaly`, `skip_spike`), `severity` (`low`, `medium`, `high`), `payload`.

### 2.2 Eloquent Models & Scopes

- `CourseModule`: Extends `TenantModel`, belongs to `Course`, has many `Lesson`s ordered by `sort_order`.
- `Lesson`: Belongs to `CourseModule`, has many `LessonMaterial`s, `MediaAsset`s, and `LessonProgress`.
- `LessonMaterial`: Extends `TenantModel`, belongs to `Lesson`.
- `LessonProgress`: Extends `TenantModel`, composite tracking of student progress.
- `VideoEvent`: Extends `TenantModel`, immutable event record.
- `AbuseSignal`: Extends `TenantModel`, security flag for suspicious playback activity.

## 3. Domain Services & APIs

### 3.1 ProgressAggregator (`App\Domain\Education\Services\ProgressAggregator`)

- Server-authoritative aggregation engine.
- Processes batched video events sequentially.
- Anomaly Detection: Flags skips forward greater than 60 seconds during heartbeat intervals as potential speed abuse.
- Completion Trigger: Automatically stamps `completed_at = now()` when completion reaches ≥ 90% or on `end` event.
- Tracks `watch_seconds` and increments `rewatch_count` on repeated views.

## 4. Frontend Implementation

### 4.1 Staff Screens (Course Builder)

1. **Teacher Courses Index (`/teacher/courses`):**
   - Modern cards grid with level badges (`مبتدئ`, `متوسط`, `متقدم`), status badges (`منشور`, `مسودة`), access badges (`مجاني`, `باقة اشتراك`).
   - Summary statistics (module count, lesson count).
   - Direct link to Course Builder workspace (`/teacher/courses/${id}`).
   - Modal for creating new courses.
   - Filter tabs: 'الكل', 'منشور', 'مسودة', 'مؤرشف' and instant search.

2. **Course Builder Workspace (`/teacher/courses/[id]`):**
   - Three dedicated tabs:
     - **منهج المقرر (Outline):** Modules accordion, add module modal, add lesson modal, drag-free sort reordering, upload/link materials, lesson delete and status toggles.
     - **تقدم الطلاب (Student Progress):** Real progress analytics table showing enrolled students, lessons completed count, overall completion percentage, and last active timestamp.
     - **إعدادات المقرر (Settings):** Update title, code, level, free/paid status, and publish/unpublish action.

### 4.2 Student Screens (Course Player)

1. **Student Courses Dashboard (`/student/courses`):**
   - Completely removed simulated AI Tutor canned responses (`setTimeout`, `Math.random()`).
   - Displays student's enrolled courses with actual progress bars computed from backend `educationApi.getMyProgress()`.
   - Course catalog with level filters and search.

2. **Student Course Overview (`/student/courses/[id]`):**
   - Course hero section with teacher details, overall completion progress, and "متابعة التعلم" CTA linking directly to the first incomplete lesson.
   - Complete syllabus outline showing modules, lessons, duration, free preview badges, and lock indicators for locked lessons.

3. **Dedicated Student Player (`/student/courses/[id]/lessons/[lessonId]`):**
   - Distraction-free layout with collapsible syllabus drawer.
   - HTML5 video playback with 15-second heartbeats to `POST /lessons/{id}/events`.
   - Playback resume: loads `last_position_seconds` on start.
   - Dynamic floating anti-piracy watermark overlay displaying student name, student code, and phone/email, randomly moving every 9 seconds.
   - Materials & Attachments tab with signed downloads.
   - Previous and Next lesson navigation controls.
   - Manual "تحديد كمكتمل" button for text/document lessons.
   - Gated content handling: 403 screen with direct link to `/student/plans` when user lacks access.
